# KerbNoteLite v1.3.0 - Short Description for SpaceDock

## Short Description (for main field)

Advanced note-taking and alarm system with terrain warnings (GPWS), resource monitoring, and massive performance boost (80% faster). Write mission notes, set location-based alarms, get gear warnings, altitude callouts, and low-fuel alerts. Never miss a milestone or run out of resources!

## Installation Instructions (short)

1. Download ZIP
2. Extract to [KSP]/GameData/
3. Launch KSP
4. Click KerbNote icon in toolbar
5. Done!

Upgrading? Your notes and alarms are preserved automatically.
