KerbNoteLite v1.3.1
===================

Comprehensive note-taking and advanced alarm system for Kerbal Space Program.

## Installation

Copy this entire `KerbNoteLite` folder into your KSP `GameData/` directory.

## Features

✅ Multi-tab note-taking system
✅ Location-based alarms (body, situation, VAB/SPH, Space Center)
✅ Terrain proximity warnings (GPWS-style)
✅ Resource monitoring alarms
✅ Stall warning system
✅ Floating mini-notes
✅ Customizable UI skins
✅ Built-in calculator

## Getting Started

1. Launch KSP
2. Look for the KerbNote icon in the toolbar (or press Alt+N)
3. Create notes, set alarms via the alarm panels
4. Configure advanced alarms via the Global Alarm Panel (left side icon)

## Configuration

All settings are saved per-game-save in:
`GameData/KerbNoteLite/AlarmsAndNotes/`

Global alarm configs:
- `TerrainAlarmConfig.cfg` - Terrain/GPWS settings
- `ResourcesAlarmConfig.cfg` - Resource monitoring settings

## Custom Skins

Place custom texture packs in:
`texture_pack/YourSkinName/Textures/`

See `texture_pack/README.md` for details.
