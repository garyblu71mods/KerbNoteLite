# KerbNoteLite Textures

This folder contains the default UI textures for KerbNoteLite.

## Required Files

### Core UI Textures:
- `Background_window.png` - Main window background
- `NoteWindow.png` - Note window background
- `Button.png` - Default button state
- `ButtonHover.png` - Button hover state
- `ButtonClick.png` - Button pressed state

### Tab Textures:
- `Tab.png` - Default tab state
- `TabHover.png` - Tab hover state
- `TabClick.png` - Tab pressed/active state
- `TabRed.png` - Red tab (for delete/warning actions)

### Alarm Bar Textures:
- `Alarm_bar.png` - Vertical alarm bar (for right panel)
- `Alarm_bar_horizontal.png` - Horizontal alarm bar (for bottom panel)

## Custom Skins

To create custom skins, place your texture pack in:
`GameData/KerbNoteLite/texture_pack/YourSkinName/Textures/`

See `../texture_pack/README.md` for more information.
