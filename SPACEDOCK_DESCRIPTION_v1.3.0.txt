# KerbNoteLite v1.3.0 - SpaceDock Description

## Overview

KerbNoteLite is a comprehensive note-taking and advanced alarm system for Kerbal Space Program. Write mission notes, set location-based alarms, monitor resources, and get terrain warnings - all integrated seamlessly into your game.

---

## What's New in v1.3.0

### ?? Terrain Proximity Alarms (GPWS)
Aviation-style collision avoidance system with:
- **Pull-Up warnings** for low altitude + fast descent
- **Terrain Ahead prediction** with 6-second look-ahead
- **Altitude callouts** (200m down to 10m, plus "Landed")
- **Gear warnings** with roll suppression
- **Sink Rate warnings** for safe landings
- Independent volume control and smart suppression

### ?? Resource Monitoring
Never run out of fuel or power:
- Monitor ElectricCharge, LiquidFuel, Oxidizer, MonoPropellant, and more
- Per-resource thresholds (0-100%)
- Depletion warnings at 0%
- EVA jetpack MonoPropellant monitoring
- Communication signal strength alerts

### ? Massive Performance Boost
**80-85% faster** than previous versions:
- Optimized alarm triggering (70-90% faster)
- Cached expensive Unity operations
- Eliminated memory allocations in hot paths
- Smooth gameplay even with all alarms active

### ??? Global Alarm Panel
Centralized control for all systems:
- Slide-out panel for easy access
- One-click enable/disable for each alarm type
- Persistent configuration
- Clean tab-style UI

---

## Core Features

### ?? Note-Taking System
- **Multi-tab notebook** with unlimited tabs
- **Rich text editing** with 5 zoom levels
- **Undo support** (Ctrl+Z)
- **Per-save storage** - different notes per game save
- **Floating mini-notes** for quick reference

### ?? Location-Based Alarms
- Trigger on celestial body + situation combinations
- Actions: Mini-note popup, Kerbal vocal sounds, stop time warp
- All vessel situations supported (Orbiting, Flying, Landed, etc.)
- Editor and Space Center triggers

### ?? Customization
- **Multiple UI skins** included
- **Custom skin support** - add your own themes
- **Draggable and resizable** windows
- **Application launcher** integration

## Installation

1. Download the latest release
2. Extract to `[KSP]/GameData/`
3. Launch KSP
4. Look for the KerbNote icon in the toolbar

**Upgrading?** Your existing notes and alarms are preserved automatically.

---

## Quick Start

1. **Click toolbar icon** to open KerbNote
2. **Create note** with "+" button
3. **Set alarm** via sidebar for location-based triggers
4. **Enable terrain/resource alarms** via Global Alarm Panel

**Full documentation included in mod folder!**

## Configuration

All settings accessible via in-game UI:
- **Terrain alarms**: Altitude thresholds, volume, aircraft filter
- **Resource alarms**: Per-resource thresholds, enable/disable
- **Global settings**: Skins, save switching, help system

No config file editing required!
